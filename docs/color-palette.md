# IMCS Scheduler — Color Palette (v1)

Primary color is the blue from the IMCS logo — used only for buttons, active
nav items, links, and key highlights. It is NOT a background color.

## Primary Blue
- Light mode: `#16324F`
- Dark mode: `#3D6E9E`

## Light Theme
- Background: `#F5F5F5`
- Cards: `#FFFFFF`
- Text: `#1A1A1A`

## Dark Theme
- Background: `#0A0A0A`
- Cards: `#171717`
- Text: `#F5F5F5`

## Status Indicators (live dashboard — kept outside the brand palette on purpose)
- Available: `#22C55E` (green)
- Busy: `#F59E0B` (amber)
- Conflict / error: `#EF4444` (red)

---
This is a starting point — subject to change once implemented and reviewed
in the actual app.
